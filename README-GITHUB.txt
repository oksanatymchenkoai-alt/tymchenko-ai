TYMCHENKO.AI — публікація на GitHub Pages

1. Розпакуйте ZIP-файл.
2. Завантажте ВСІ файли та папки з цього архіву в корінь репозиторію GitHub.
3. У GitHub відкрийте Settings → Pages.
4. У розділі Build and deployment виберіть:
   Source: Deploy from a branch
   Branch: main
   Folder: / (root)
5. Натисніть Save і зачекайте кілька хвилин.

Важливо: файли content/resources.json та папка content мають залишитися на місці.
PDF зберігаються на Google Drive. Для кожного PDF у Google Drive потрібно встановити доступ «Усі, хто має посилання».
